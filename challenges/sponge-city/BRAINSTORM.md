# Brainstorm — Make Basel a Sponge

## Problem beneath the brief

The maps largely already exist. The deeper problem may be **choosing interventions across administrative, disciplinary and data silos**.

## Broken decision

> Given all available evidence about one real place, what intervention should we investigate and why?

## Candidate shared object: place intervention case

Possible fields:

- place
- heat exposure
- runoff exposure
- canopy / shade
- existing vegetation
- impervious surface
- sensitive uses / populations
- candidate intervention
- expected benefits
- trade-offs
- feasibility unknowns
- source evidence
- decision needed

## Relationship to existing work

- Basel Spatial Graph
- DataFit / evidence composition
- RunO2 provenance-first spatial reasoning
- semantic compilation from heterogeneous evidence to an intervention case

## Ideas

### From map to case

Instead of another citywide overlay, select a place and produce an inspectable intervention case:

```
PLACE
↓
OBSERVED RISKS
↓
POSSIBLE INTERVENTIONS
↓
BENEFITS
↓
TRADE-OFFS
↓
UNKNOWNS
↓
DECISION NEEDED
```

### Cross-office decision object

A shared object could let heat, water, trees, mobility and planning actors look at the same proposed intervention without requiring them to use the same source system.

## Open questions

- Which scale makes the strongest defensible demo?
- Can intervention feasibility be supported by available data rather than invented?
- What would a planner genuinely need on Monday morning?
